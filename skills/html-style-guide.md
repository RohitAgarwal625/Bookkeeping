# HTML Style Guide — Design Artifacts

All HTML files generated by the design skills **must** follow this style guide to ensure visual consistency across all iterations and features.

---

## 1. Theme: Light, Elegant, Readable

| Token | Value | Usage |
|---|---|---|
| `--color-bg` | `#ffffff` | Page background |
| `--color-bg-card` | `#f8f9fa` | Card / section backgrounds |
| `--color-bg-sidebar` | `#f1f3f5` | Sidebar / TOC background |
| `--color-text` | `#1a1a2e` | Primary text |
| `--color-text-secondary` | `#6c757d` | Secondary / muted text |
| `--color-heading` | `#0f172a` | Headings |
| `--color-accent` | `#2563eb` | Links, active states, primary actions |
| `--color-accent-hover` | `#1d4ed8` | Hovered links / buttons |
| `--color-border` | `#e2e8f0` | Borders, dividers |
| `--color-success` | `#059669` | Resolved, verified, pass |
| `--color-success-bg` | `#ecfdf5` | Success badge/row background |
| `--color-warning` | `#d97706` | Accepted, partial, in-progress |
| `--color-warning-bg` | `#fffbeb` | Warning badge/row background |
| `--color-error` | `#dc2626` | Open, failed, critical |
| `--color-error-bg` | `#fef2f2` | Error badge/row background |
| `--color-info` | `#2563eb` | Informational |
| `--color-info-bg` | `#eff6ff` | Info badge/row background |
| `--color-neutral` | `#64748b` | Deferred, won't fix |
| `--color-neutral-bg` | `#f1f5f9` | Neutral badge background |

| Element | Font | Size | Weight | Line Height |

## 4. Mandatory UI Components

### 4.1 Sticky Sidebar (Table of Contents)
- Fixed left, full height
- Background: `var(--color-bg-sidebar)`
- Active section highlighted with `var(--color-accent)` left border
- Scroll-spy: highlights current section as user scrolls
- Collapsible on mobile (hamburger icon)

### 4.2 Top Breadcrumb Bar
- Sticky top, white background with subtle bottom border
- Format: `Feature Name > Iteration 02 > Grill`
- Each segment is a clickable link
- Right side: status badge (e.g., `⚠ NEEDS REVISION`)

### 4.3 Status Badges
```html
<!-- Severity -->
<span class="badge badge-critical">CRITICAL</span>   <!-- bg: #fef2f2, color: #dc2626, border: 1px solid #fecaca -->
<span class="badge badge-major">MAJOR</span>          <!-- bg: #fffbeb, color: #d97706, border: 1px solid #fde68a -->
<span class="badge badge-minor">MINOR</span>          <!-- bg: #f1f5f9, color: #64748b, border: 1px solid #e2e8f0 -->

<!-- Status -->
<span class="badge badge-resolved">✅ RESOLVED</span>      <!-- bg: #ecfdf5, color: #059669 -->
<span class="badge badge-open">✗ OPEN</span>               <!-- bg: #fef2f2, color: #dc2626 -->
<span class="badge badge-validated">✓ VALIDATED</span>      <!-- bg: #ecfdf5, color: #059669 -->
<span class="badge badge-accepted">⚠ ACCEPTED</span>       <!-- bg: #fffbeb, color: #d97706 -->
<span class="badge badge-in-progress">◉ IN PROGRESS</span> <!-- bg: #eff6ff, color: #2563eb -->
<span class="badge badge-deferred">⏳ DEFERRED</span>       <!-- bg: #f1f5f9, color: #64748b -->

<!-- Verdict -->
<span class="badge badge-pass">✅ PASS</span>
<span class="badge badge-fail">❌ FAIL</span>
<span class="badge badge-conditional">⚠️ CONDITIONAL PASS</span>
```

### 4.4 Issue Tracker Table
- Zebra-striped rows
- Color-coded status column
- Sortable headers (optional, via JS)
- Sticky header row
- Columns: ID | Source | Severity | Description | Introduced | Status | Resolution

### 4.5 Progress Bar (Convergence)
- At top of rethink.html and index.html
- Shows: `14 / 17 issues resolved (82%)`
- Segmented bar: green (resolved), yellow (in-progress), red (open)
- Appears below breadcrumb

### 4.6 Collapsible Sections
```html
<details class="collapsible">
  <summary>G-014 — Duplicate processing after crash <span class="badge badge-critical">CRITICAL</span></summary>
  <div class="collapsible-content">
    ... detailed content ...
  </div>
</details>
```
- Subtle animation on open/close
- Open indicator: chevron rotation

### 4.7 Before / After Diff Blocks
```html
<div class="diff-container">
  <div class="diff-before">
    <h4>Before (v1)</h4>
    <div class="mermaid">...</div>
  </div>
  <div class="diff-after">
    <h4>After (v2)</h4>
    <div class="mermaid">...</div>
  </div>
</div>
```
- Side by side on desktop, stacked on mobile
- Before: subtle red-tinted border left
- After: subtle green-tinted border left

### 4.8 Inter-File Navigation
- Bottom of every page:
```
← Previous: iteration-01/rethink.html    |    Next: iteration-02/grill.html →
```
- Also: `↑ Back to Feature Index`

### 4.9 Risk Matrix (for rethink & verification)
- 2D grid: Likelihood (x) × Impact (y)
- Cells color-coded by combined severity
- Issue IDs placed in cells

## 5. Diagrams — Mermaid.js

### 5.1 Loading
```html
<script src="https://cdn.jsdelivr.net/npm/mermaid/dist/mermaid.min.js"></script>
<script>
  mermaid.initialize({
    startOnLoad: true,
    theme: 'neutral',
    fontFamily: 'Inter, system-ui, sans-serif',
    flowchart: { curve: 'basis', padding: 20 },
    sequence: { mirrorActors: false, messageAlign: 'center' },
    themeVariables: {
      primaryColor: '#e0e7ff',
      primaryTextColor: '#1a1a2e',
      primaryBorderColor: '#2563eb',
      lineColor: '#94a3b8',
      secondaryColor: '#f1f5f9',
      tertiaryColor: '#ecfdf5'
    }
  });
</script>
```

### 5.2 Diagram Wrapper
Every diagram must be wrapped:
```html
<figure class="diagram">
  <div class="mermaid">
    graph TD
      A[Start] --> B[Process]
  </div>
  <figcaption>Figure 1: Process overview</figcaption>
</figure>
```
- Light border, `border-radius: 8px`
- `figcaption`: centered, muted text, italic

### 5.3 Diagram Types to Use
| Diagram | When |
|---|---|
| `flowchart TD/LR` | Process flows, architecture |
| `sequenceDiagram` | Component interactions, API calls |
| `stateDiagram-v2` | State machines, lifecycle |
| `erDiagram` | Data models, entity relationships |
| `gantt` | Timelines, iteration roadmaps |
| `graph TD` | Dependency graphs |
| `pie` | Issue distribution (optional) |

## 9. Smooth Scroll & Scroll Spy

```html
<style>html { scroll-behavior: smooth; }</style>
```

Scroll-spy via JS:
```javascript
const sections = document.querySelectorAll('section[id]');
const tocLinks = document.querySelectorAll('.sidebar a');

window.addEventListener('scroll', () => {
  let current = '';
  sections.forEach(section => {
    if (window.scrollY >= section.offsetTop - 100) {
      current = section.getAttribute('id');
    }
  });
  tocLinks.forEach(link => {
    link.classList.toggle('active', link.getAttribute('href') === '#' + current);
  });
});
```
