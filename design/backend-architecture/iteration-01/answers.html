Critical Issues

G-001 — Auth Impersonation CRITICAL → FIX

Add Session table. On login, generate random UUID token (24h TTL). Frontend sends Authorization: Bearer {token}. Middleware validates against Session table. Prevents trivial impersonation (need to know token, not just wallet). Phase 4 replaces with JWT.

GET /api/users/:walletAddress -> { user, sessionToken }
All requests: Authorization: Bearer {sessionToken}

G-006 — Simultaneous Payments CRITICAL → FIX

Independent blockchain transactions. No netting. Our DB is a record of Pi blockchain, not the source of truth. Each pending tx completes/fails independently. Reconciliation job (G-023) handles stuck ones.

G-009 — Float Precision CRITICAL → FIX

Switch to Decimal @db.Decimal(18, 7) in Prisma (PostgreSQL NUMERIC). API serializes via parseFloat(amount.toString()). Standard for financial data.

G-018 — Idempotency Optional CRITICAL → FIX

Make idempotencyKey REQUIRED on POST /api/transactions. Frontend generates UUID v4 when form renders (not on submit). Retries send same key.

G-023 — Pending TX Stuck CRITICAL → FIX

30-min TTL on pending transactions (expiresAt field). Cron job every 5 min checks Pi Platform API for expired pending txs. Updates to completed/expired. Phase 4 implementation.

Major Issues

G-003 — IP Rate Limiting MAJOR → FIX

Two-tier: IP-based (200/min) for unauthenticated, user-based (100/min) for authenticated, write-specific (20/min).

G-004 — Wallet Format MAJOR → FIX

Permissive (any string, min 1, max 100) for Phase 1-3. Strict Stellar validation (/^G[A-Z2-7]{55}$/) in Phase 4.

G-005 — XSS MAJOR → FIX

Use xss npm package in Zod transform to strip HTML from description, name, displayName fields.

G-010 & G-025 — Contact Totals / N+1 MAJOR → FIX

Single raw SQL with LEFT JOIN + GROUP BY computes totalCredit, totalDebit, lastSeen for all contacts in one query.

SELECT c.*, COALESCE(SUM(CASE WHEN t.type='credit' THEN t.amount END),0) as "totalCredit",
  COALESCE(SUM(CASE WHEN t.type='debit' THEN t.amount END),0) as "totalDebit",
  MAX(t.timestamp) as "lastSeen"
FROM "Contact" c LEFT JOIN "Transaction" t ON t."contactId"=c.id
WHERE c."userId"=$1 GROUP BY c.id

G-011 — Delete Blockchain TX MAJOR → FIX

Soft-delete (deletedAt field). Block deletion of source=pi_network transactions (return 403).

G-012 — Audit Trail MAJOR → FIX

G-013 — Pool Exhaustion MAJOR → FIX

G-021 — Migration Failure MAJOR → FIX

G-022 — No Staging MAJOR → ACCEPTED

G-024 — Payment Completion Idemp MAJOR → FIX

G-026 — ContactId Ownership MAJOR → FIX
