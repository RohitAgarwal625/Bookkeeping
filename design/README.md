# Design Directory
Contains iterative architecture & design convergence artifacts.
## Structure
- `design/<feature-name>/index.html` — Master dashboard
- `design/<feature-name>/iteration-NN/` — Each iteration's artifacts
- `design/<feature-name>/final/architecture.html` — Converged design
## Skills (in `skills/`)
- `proposal-skill.md` → generates proposal.html
- `grill-skill.md` → generates grill.html
- `design-verification-skill.md` → generates verification.html
- `iterative-architecture-convergence-skill.md` → orchestrates the loop
